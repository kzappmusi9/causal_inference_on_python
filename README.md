## Part 0: MMMを学ぶ前の前提知識

### 0-1. MMMとは

MMM (Marketing Mix Modeling) は、売上やコンバージョンなどの目的変数に対して、広告費、価格、販促、季節、競合などの要因がどの程度貢献しているかを定量的に分析する手法です。

主な狙いは次のとおりです。

- どのチャネルが売上に効いているかを把握する
- 予算配分を最適化する
- 施策のインパクトを比較する
- 施策の過去実績から将来予測を行う

MMMでは、単純に「広告費が多いほど売上が増える」という関係だけではなく、次のような要素を考慮します。

- 施策ごとの効果の強さ
- 効果の発現タイミング
- チャネル間の相互作用
- 季節やイベントの影響
- 価格や在庫の影響

MMMは、広告最適化や予算設計を行う上で非常に有効な枠組みです。

#### 学習ポイント

- MMMは「因果推論」そのものではなく、因果に近い説明モデルとして使う
- 売上への要因分解が重要である
- 実務ではデータ品質と仮定の妥当性が成果に直結する

### 0-2. データの基本

MMMで扱うデータは、通常「時間を軸にした縦長データ」になります。一週間や月単位で集計されたデータを用い、各期間における売上と施策の状態を紐づけます。

代表的な変数には次のようなものがあります。

- 売上 (Sales)
- 広告費 (TV, Search, Display, SNS など)
- 価格
- 施策やキャンペーン
- 季節要因 (月、週、イベント)
- 外部環境 (競争、天候、在庫、景気)

#### 重要な考え方

- 時系列データは単なる横断データではない
- 変数のスケールや単位に注意する
- 欠損値や異常値の扱いが結果に影響する
- 変数間に相関がある場合は、モデル設計に注意する

典型的な MMMの入力データ例:

| 日付 | 売上 | TV広告費 | 検索広告費 | 価格 | 週次イベント |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2024-01-01 | 120000 | 20000 | 8000 | 3500 | 0 |
| 2024-01-08 | 135000 | 22000 | 9000 | 3400 | 1 |

このようなデータをもとに、どの変数が売上の変動に寄与したかを推定します。

#### 学習ポイント

- 変数の意味とデータの粒度を理解する
- 時系列データは「トレンド」「季節性」「イベント」などを含む
- 学習の前にデータの説明変数と目的変数を整理することが重要

### 0-3. 評価指標

MMMでは、モデルの良し悪しを評価するために指標を用います。

#### 代表的な評価指標

- RMSE (Root Mean Squared Error)
  - 予測誤差の大きさを評価する指標
  - 誤差を二乗して平均し、平方根をとる
- MAE (Mean Absolute Error)
  - 誤差の絶対値の平均
  - 解釈しやすい
- MAPE (Mean Absolute Percentage Error)
  - 誤差を割合で表す
  - 変動が大きい場合には扱いに注意
- R²
  - 説明力の指標
  - 変動のどれだけがモデルで説明できているかを見る

#### 実務で使う指標

MMMでは、単に予測精度だけでなく、以下の観点も重要です。

- 予測が実際の売上変動をどれだけ再現しているか
- 係数の符号や大きさが妥当か
- 期間ごとの差異が過大でないか
- 施策の効果解釈が合理的か

#### 学習ポイント

- 指標は「良い」と「悪い」を一つで決めるものではない
- 予測精度と解釈可能性は両立させる必要がある
- MMMでは、推定結果の妥当性の確認も重要になる

## Part 1: 統計学の基礎

### 1-1. 回帰分析

回帰分析は、目的変数と説明変数の関係を定量化する基本的な手法です。

- 線形回帰: 一次式で関係を表す
- 重回帰: 複数の説明変数を同時に扱う
- 係数: 各説明変数が目的変数に与える影響の大きさ
- 誤差項: 観測できない要因やノイズ

MMMでは、売上を目的変数として、広告費や価格などを説明変数に使うことが多く、回帰分析の考え方が基本になります。

### 1-2. 時系列データ

時間順に並ぶデータを時系列データと呼びます。MMMでは多くの場合、日次・週次・月次で集計された時系列データを扱います。

時系列データでは次のような特徴が現れます。

- トレンド
- 季節性
- 周期性
- 自己相関
- 外れ値

これらを考慮しないと、広告効果の推定が誤る可能性があります。

### 1-3. 前処理

モデルに入れる前に、データを整える作業が必要です。

典型的な前処理には以下があります。

- 欠損値補完
- 外れ値除去
- 変数の標準化
- 期間の整列
- 季節変数の生成
- ログ変換

前処理は、モデルの安定性と解釈可能性を高めるために重要です。

## Part 2: MMMのモデル設計

### 2-1. 線形回帰

最も基本的な MMM は、売上を説明変数の線形結合として表すモデルです。

$$
Y_t = \beta_0 + \beta_1 X_{1,t} + \beta_2 X_{2,t} + \cdots + \epsilon_t
$$

ここで、

- $Y_t$: 売上
- $X_{i,t}$: 各施策·要因の値
- $\beta_i$: 係数
- $\epsilon_t$: 誤差

線形回帰は解釈が簡単ですが、現実のマーケティング効果は非線形や遅延があるため、単純な線形だけでは不十分なことが多いです。

### 2-2. 非線形効果

広告効果は、投入額が増えるほど比例的に売上が増えるわけではありません。

たとえば、

- 最初の数万円は効果が大きい
- ある一定額を超えると逓減する
- 施策ごとに飽和曲線を持つ

このような現象は、ロジスティック型やハンマー型の関数を使って表現します。

非線形効果を入れることで、現実的な効果の変化を再現できます。

例えば、Hill 関数は次のような形で表されます。

$$
\text{response}(x) = \frac{x^\alpha}{k^\alpha + x^\alpha}
$$

ここで、

- $x$: 施策の投入量
- $k$: 半飽和点
- $\alpha$: 曲線の急峻さ

この式では、投資量が少ないときは効果が伸びやすく、ある水準を超えると効果が頭打ちになることを表します。売上が一定の程度までは急に伸びるが、さらに投資しても増加幅が小さくなる、という「飽和」のイメージです。

#### Pythonで見る Hill 関数

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 100, 400)


def hill(x, k=30, alpha=1.5):
    return (x ** alpha) / (k ** alpha + x ** alpha)

for k in [10, 30, 60]:
    y = hill(x, k=k, alpha=1.5)
    plt.plot(x, y, label=f'k={k}')

plt.title('Hill function: nonlinear saturation')
plt.xlabel('Marketing spend')
plt.ylabel('Response')
plt.grid(alpha=0.3)
plt.legend()
plt.show()
```

このグラフを見ると、投入額が増えるほど効果は増えますが、ある程度以上では増加率が鈍くなることが分かります。これは「広告の効果には限界がある」という現実的な考え方を表しています。

### 2-3. 遅延効果

広告はすぐに売上に現れるわけではなく、数日後や数週間後に効果が出ることがあります。

たとえば、

- 広告露出 → クリック → 購買
- キャンペーンの影響が数週間続く
- 施策が持続的に売上を押し上げる

このような遅延効果をモデルに入れるために、ラグ付き変数や分布遅延を使います。MMMでは「今週の広告が来週以降の売上にどう効くか」を考えるのが重要です。

代表的な遅延効果の扱い方として adstock がよく使われます。adstock は、ある期間の広告効果が次の期間にも残るという考え方です。

$$
A_t = X_t + \theta A_{t-1}
$$

ここで、

- $X_t$: 今期の広告投入量
- $A_t$: 効果が蓄積された値
- $\theta$: 残留率

$\theta$ が大きいほど、効果が長く残ります。たとえば、今週の広告が次週も効くようなイメージです。

#### Pythonで見る adstock

```python
import numpy as np
import matplotlib.pyplot as plt

weeks = np.arange(12)
spend = np.array([0, 2, 5, 4, 3, 2, 6, 7, 5, 4, 2, 1], dtype=float)


def adstock(x, theta=0.5):
    y = np.zeros(len(x), dtype=float)
    for t in range(len(x)):
        y[t] = x[t] + (theta * y[t - 1] if t > 0 else 0.0)
    return y

for theta in [0.2, 0.5, 0.8]:
    effect = adstock(spend, theta=theta)
    plt.plot(weeks, effect, marker='o', label=f'theta={theta}')

plt.plot(weeks, spend, linestyle='--', color='black', linewidth=1.5, label='original spend')
plt.title('Adstock: delayed carryover effect')
plt.xlabel('Week')
plt.ylabel('Effect')
plt.grid(alpha=0.3)
plt.legend()
plt.show()
```

この図では、同じ広告投資でも $\theta$ が大きいほど、効果が長く残り、翌週以降にも影響が続くことを視覚的に確認できます。

#### まとめ

- 非線形効果: 効果は「飽和」し、投資を増やしても一定以上では伸びにくくなる
- 遅延効果: 効果は「残留」し、今期の広告が後期にまで効く
- MMMでは、これらを同時に考えることで、現実のマーケティング効果をより正確に表現できる

実際の分析では、Hill 関数と adstock を組み合わせて、広告投資の効果曲線と持続性を同時にモデル化することがよくあります。

## Part 3: 推定の仕組み

### 3-1. 最尤推定

最尤推定は、観測データが最も生じやすいようなパラメータを推定する方法です。

- 事前にモデルを仮定する
- そのモデルが与えられたデータをどれだけ説明できるかを評価する
- もっとも確からしい係数を選ぶ

MMMでは、係数や遅延パラメータをこの方法で推定することがよくあります。

### 3-2. 最適化

最尤推定やベイズ推定の実務では、「目的関数を最小化または最大化する」必要があります。

代表的な最適化手法には以下があります。

- 勾配法
- 確率的勾配降下法（SGD）
- L-BFGS などの準ニュートン法

MMMのような複雑なモデルでは、最適化の安定性や収束性が重要になります。

### 3-3. MCMC

MCMC (Markov Chain Monte Carlo) は、複雑な確率モデルの後部分布を近似的にサンプルする手法です。

代表的な手法:

- Metropolis-Hastings
- Gibbs Sampling
- Hamiltonian Monte Carlo (HMC)

MCMCは、ベイズ推定において非常に重要で、係数の不確実性を評価するのに使われます。

### 3-4. ベイズ推定

ベイズ推定では、未知の係数を確率変数として扱い、事前分布とデータから事後分布を求めます。

メリット:

- パラメータの不確実性を扱える
- 事前知識を取り入れられる
- 信頼区間や確率的な解釈がしやすい

MMMでは、広告効果に不確実性がある場合に、ベイズ推定が有効です。

## Part 4: 実装と診断

### 4-1. PyMC実装

PyMCは、ベイズモデリングのための Python ライブラリで、MMMのような複雑な時系列モデルの実装に適しています。

代表的な実装上のポイント:

- 変数定義
- 確率分布の設定
- 事前分布の決定
- 推論の実行
- 事後分布の可視化

PyMCを使うと、モデルの仮定と不確実性を比較的自然に扱えます。

### 4-2. 推定結果の診断

推定が成功した後でも、結果を診断する必要があります。

主な観点:

- 収束しているか
- 係数に異常がないか
- 事後分布が妥当か
- 予測性能が十分か
- ラグや非線形効果が自然か

診断には、R-hat、トレースプロット、事後分布の確認などが使われます。

### 4-3. 感度分析

感度分析は、入力条件の変動が結果にどのように影響するかを確認する手法です。

たとえば、

- 広告費の増減を変えたときの売上変化
- 価格のばらつきが結果にどう効くか
- 期間の変更による係数の変化
- 外部要因の変動に対するロバスト性

感度分析を行うことで、モデルの頑健性や意思決定への信頼性を高められます。
